# College Management System (Java OOP)

A console-based beginner Java project inspired by the class structure visible in the provided video. The project keeps `Admission`, `Student`, `Course`, and `Library` classes together in `Main.java`, similar to a simple classroom demonstration, with a few improvements.

## Improvements
- Menu-driven program
- Register a student from the menu
- Input validation for menu choice and semester
- Private fields and constructors
- Clearer output labels and consistent formatting
- Library book list using `ArrayList`

## Requirements
Java JDK 8 or newer.

## Run
From the project folder:

```bash
javac -d out src/Main.java
java -cp out Main
```

## Files
- `src/Main.java` — main program and all four supporting classes
- `.gitignore` — ignores generated `.class` files and IDE folders

## Note
This is a similar, improved implementation based on the class names and general layout visible in the video; it is not a verbatim transcription of every line.
